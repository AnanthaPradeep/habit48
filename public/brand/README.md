# Luminous brand

The application uses the unmodified production vectors from MR-Luminous-Kit. Pearl supplies light theme logos and the installed app icon. Midnight supplies dark theme logos. The kit describes its outlined wordmark as a DejaVu Sans Bold stand-in for the concept board's custom lettering.

The Latin variable Inter and Sora webfonts are served locally. Their SIL Open Font License notices ship alongside the files. Editorial display headings retain the existing serif face.

The manifest identity, start URL and scope are stable. The build regenerates the service-worker cache using the versioned artwork. If Chrome still displays an old installed icon, open My Routine online and relaunch the shortcut after the update. If the OS retains the old artwork, sign in in Chrome and confirm recent entries are synced before removing the shortcut and reinstalling from Chrome. Keep site data when the browser offers that choice.
